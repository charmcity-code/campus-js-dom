# DOM Practice

Four small examples for the DEV140 discussion section on DOM manipulation. They match what Homework 7 and Project Milestone 4 ask for.

## Today's four ideas

1. Click changes content
2. Typing changes style
3. Forms explain mistakes
4. Lists grow

## Run it

1. Open this folder in VS Code.
2. Open `index.html` and start Live Preview or Live Server.
3. Edit `script.js` and save. The preview updates right away.

## Files

- `index.html`: the page, with all four examples.
- `style.css`: the styles.
- `script.js`: the JavaScript, one block per example.

## The examples

| # | Example | What it shows | Used in |
| --- | --- | --- | --- |
| 1 | A button changes content | Select an element, listen for a click, change `textContent` | Homework 7, Milestone 4 |
| 2 | Typing changes a style | The `input` event and `classList.toggle` | Homework 7 |
| 3 | Form validation | Errors on the page, `aria-invalid`, focus on the first invalid field | Milestone 4 |
| 4 | A list that grows | `createElement` and `appendChild` | Homework 7 |

The form never sends anything. It only checks what you typed.

## Using it for your own work

This is practice code. Copy the pattern, not the page. Use your own IDs, your own text and your own styles, and run the keyboard test (Tab, Enter, Space) on what you build.
